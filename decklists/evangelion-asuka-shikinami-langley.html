How it plays

From public tournament lists

Evangelion - Asuka Shikinami Langley is an aggro list. Standard tier 3 on the latest TCG Contender snapshot. Deep redundancy across key named characters (4x Asuka Shikinami Langley 012/013, 4x Mari Makinami Illustrious 017/018) means the deck reliably finds its core pieces even without dedicated tutors.. Multiple raid-eligible copies of the same characters (e.g., three different Mari Makinami Illustrious print variants) allow for raid upgrades that improve stats turn over turn as the game progresses..
